# 闪念盒 memoflow

flomo 式低摩擦速记 + 每日回顾 + Tangu AI 周整理,Forsion 桌面插件。
本插件**吸收并取代上一批的 quick-capture 小件**:快速记一条(命令 + 状态栏)在这里是一等入口,且记下的内容进同一套月文件、回顾与整理体系。

> 本仓是 [Forsion](https://github.com/Changan-Su/Forsion)(AI 原生笔记 + 内置 Tangu Agent 的本地优先桌面工作台)的社区插件,捆绑包(bundle)形态:UI 视图 + 随包技能 + 随包 Space。

## 安装

```bash
git clone https://github.com/Changan-Su/forsion-plugin-memoflow.git
cd forsion-plugin-memoflow
sh install.sh prod    # 安装到 ~/.forsion;开发家用 sh install.sh(默认 dev → ~/.forsion-dev)
```

重启 Forsion 桌面端后生效:命令面板「闪念盒:打开」、状态栏「✎ 闪念」,或工作台侧栏「闪念盒」Space。也可整目录压缩为单层 zip 经 Forsion 应用市场安装。

## 功能

布局:左栏是标签树(宿主列表源),主区是输入框和时间线,右栏是近 12 周热力图、统计和周整理入口。

- **速记**:输入框 Enter 发送、Shift+Enter 换行,打 `#` 出标签补全(按使用次数排);不开视图也能记 —— 状态栏「✎ 闪念」或命令面板「闪念盒:快速记一条」,单行输入直接落库。
- **Mini**:⇧⌘M 打开 Mini 切到闪念盒,上面记、下面看今天记过的,记完留在原地。布局跟容器走:高度不足 240 只留输入框,宽度够 480 显示全部标签和日期分组。「在主面板显示」带上当前标签。
- **语音速记**:输入框左下的语音按钮,按住说话(或点击开始 / 再点结束),MediaRecorder 采集 → 本机重采样成 16k WAV → Forsion 桌面语音识别桥转写,**文字先进输入框给你改**,不会直接发出。
- **标签**:规则和 Amadeus 同一口径。左栏树形,父标签计数 = 自身 + 子标签按条去重。查 `work` 命中 `work` 与 `work/urgent`,不命中 `workshop`,大小写不敏感。左栏点 = 替换,正文点 = 追加(同时满足),筛选条上清除。右键改名、合并,确认框写明改多少条。
- **时间线**:倒序按日分组,时间在左列;左栏搜索框搜标签和闪念;点热力图格子按日过滤;悬停出现操作:就地编辑 / 置顶 / 归档 / 转笔记 / 删除。「已归档」在左栏。
- **每日回顾**:每天从「7 天前更早」的全部未归档闪念里确定性抽 N 条(插件设置 `每日回顾条数`,默认 4,0 = 关闭),牌堆一次看一张,「跳过 / 转笔记 / 归档」,看完整块收起。抽卡用 `mulberry32(YYYYMMDD)`:同一天内结果稳定、跨天变化,不需要存已抽记录。
- **转笔记(免 AI)**:单条闪念一键写成 `整理/<日期>-<首行截断>.md`(带来源时间戳),原条自动打归档标。
- **AI 周整理**:命令「闪念盒:AI 周整理」把近 7 天(不足 50 条则取全库最近 50 条,归档除外)的闪念文本交给 Tangu(纯文本 run,无工具),按主题聚类产出 `整理/YYYY-Www-周整理.md` 并自动打开;进度条可取消。
- **成就**:累计 100 条 / 连续 7 天有记录。
- **中英双语**:界面文案跟随宿主语言(设置里切中/英),切换**当场生效**,详见下面「双语」一节。

## 双语(1.1.0 起)

插件界面跟着宿主的语言走(`ctx.getLocale()`),用户在设置里切中/英时**视图不重挂也当场变** —— 输入框里没发出去的草稿、正在编辑的那条(编辑框里没保存的字原样保留,不会被回读成磁盘原文)、正在录的音、跑着的 AI 周整理都不会被打断。英文按英文产品的说法写(「记下」= Capture、「闪念」= memo),不是逐字直译;计数按语言分单复数(`1 memo` / `2 memos`),列表分隔符也按语言取(中文顿号 / 英文逗号)。

**不随语言变的东西**(否则切个语言就像换了数据目录):

- 工作文件夹默认名「闪念盒」、`整理/` 子夹、周整理文件名 `YYYY-Www-周整理.md`、转笔记的文件名;
- 月文件格式、`⚑pin` / `⌫arch` 哨兵、localStorage 键、成就与引导的完成状态;
- **你自己的内容**:闪念正文、标签名一律原样,插件从不翻译用户数据。

插件自己写进产物的说明文字共**三处**,按**写入当时**的语言写,已经写好的文件不会被回改(插件从不回读解析它们):

1. 转笔记的来源行 `> 来源:闪念盒 <时间戳>` / `> Source: MemoFlow memo · <时间戳>`;
2. 周整理抬头 `> 由「闪念盒」AI 周整理生成 · <日期> · 覆盖 N 条闪念` / `> Generated by MemoFlow AI Weekly Digest · … · covering N memos`;
3. 周整理正文里每个主题下的引文小标题 `原句` / `Quotes`(它同时进给模型的提示词与最终产物)。

正文语言仍跟闪念本身走 —— 提示词明写「不要翻译」,中文闪念永远整理成中文。

### 已知缺口:命令面板 / 设置页标题要重启才更新

视图标题和左栏文案新宿主会跟着语言重算。`registerCommand.title` / `registerSetting.label` 插件这边仍是注册时取的字符串 —— 所以切换语言后,**命令面板里的「闪念盒:打开」、设置页的「每日回顾条数」**要等重启 Forsion 才跟上;插件视图内部的文案则立即生效。这是宿主侧的已知缺口,插件**刻意不做**「语言变了就反注册重来」的规避(那会打断录音、写队列和已打开的视图)。状态栏「✎ 闪念」是例外 —— 它有 `handle.update()`,切语言即时更新。

旧宿主(没有 `ctx.getLocale` / `ctx.subscribeLocale`)一律回退中文,不报错。

## 数据存哪(全部在你的笔记库)

```
<工作文件夹>/                  ← 插件设置「工作文件夹」,默认「闪念盒」
├── 2026-08.md                ← 月文件,一月一份,纯 Markdown
├── .memoflow-cache.json      ← 派生统计(热力图/标签计数),可随时重建
└── 整理/
    ├── 2026-08-05-某条转的笔记.md
    └── 2026-W32-周整理.md
```

月文件格式(数据契约):

```markdown
# 2026-08

### 2026-08-06T09:12:33.000Z
今天想到:插件生态的护城河是 Agent 纵深 #forsion #产品

### 2026-08-06T14:02:10.000Z
多行闪念
第二行也属于这条,直到下一个 ### 或 EOF。 ⚑pin
```

- 一条闪念 = `### <ISO 时间戳>` 标题 + 正文;**`###` 后不是 ISO 时间戳的行算正文**,所以正文里写三号标题不会截断。
- 标签 = 行首或空白后的 `#` + 文字、数字、`_ - /`,和 Amadeus 的 `TAG_RE` 同一条规则(`#1`、`#1/2` 不算,`a.com/#frag` 不算,`#设计,下周` 只取「设计」);标签留在正文里,渲染时高亮可点。闪念盒自带这份规则,Amadeus 关着也能用。
- 置顶 / 归档 = 正文末尾的纯文本哨兵 `⚑pin` / `⌫arch`(插件读写对称;手改文件时请保持它在正文最末尾)。
- `.memoflow-cache.json` 纯派生,任何时候可仅凭月文件全量重建 —— 视图标题行 ⋯ 菜单里的「重建缓存」即可,不需要 AI。带版本号 `v`:规则变了只重算 `tags`,`days` 是写前防线的证词,不动。
- 月文件按日期自枚举(从首次写入记下的起始月逐月推到当月),**不依赖目录列表接口**。如果你手工导入了更早月份的文件,点「重建缓存」并把起始月填小即可收编。

### 写入防线(数据安全)

- 闪念不进回收站,所以插件对「覆写整月」零容忍:**月文件读取失败(或缓存证明本月应有数据却读不到)时,一切写入/修改一律拒绝并报错**,绝不把整月闪念覆写成只剩一条;稍后重试即可。
- 时间线上的置顶/归档/编辑/删除同理:磁盘读不到就拒改,不会用内存里的旧数据整月重写(外部窗口或 agent 刚写入的条不会被覆没)。
- 标签改名 / 合并:先读完所有月份,任何一个月读不到就一字不写;确认后以写入那一刻的磁盘为准,在月文件原文上只替换标签本身,前言、块标记行、哨兵、空行逐字保留。
- 如果你**故意删掉了某个月文件**,插件会因缓存还记着账而拒写 —— 点「重建缓存」声明「以磁盘现状为准」即可继续。

## 数据流向

- 闪念本体:只落本地笔记库,不出机器。
- 语音:走 Forsion 桌面自带语音链路(设置 → 语音:本地离线 / 自带 key / Forsion 云),插件**不保存音频原文件**、不接任何第三方 ASR。
- AI 周整理:只把入选闪念的文本发给**你登录的 Forsion/Tangu 后端**;产物由插件写回本地。不用 AI 的功能(速记/回顾/转笔记)完全离线。

## 范围说明(明确不做)

- 不做 App 外推送 / 微信入口 —— 引擎渠道是另一层,本插件不碰。
- 不做闪念全库双链分析。
- 不做多设备冲突合并 —— 月文件以追加为主,冲突场景交宿主同步层。
- 不保存音频原文件,不自带 ASR 供应商、不需要额外 key。

## 旧宿主兼容

07-18 之后的宿主 API 全部可选链降级:

- 无 `registerStatusItem` → 没有状态栏入口,命令照常。
- 无 `window.tangu.transcribeAudio`(或 Web 端无桥)→ 语音按钮不渲染。
- 无 `achievements` / `activity` / `notify` → 静默跳过 / 回退 `ctx.app.notify`。
- 无 `ctx.app.workFolder` → 产物落默认文件夹「闪念盒」。
- 无 `ctx.getLocale` / `ctx.subscribeLocale`(2026-08-14 之前的宿主)→ 界面回退中文,不报错。
- 没有 `ctx.ui.mountChatBox`,或它不认新字段(句柄没有 `insertText`)→ 用插件自己的输入框,# 补全是输入框下方一排芯片。
- `ctx.listCapabilities` 没有 `tree` → 左栏平铺成「产品 / 路线图」,主区顶部加标签芯片和搜索框。
- 无 `ctx.ui.setViewHead` / `contextMenu` / `icon` / `confirm` → 标题行、重建缓存按钮、文字按钮、输入 `y` 确认都退回插件自己画。
- 连 `registerView` 都没有的远古宿主 → 视图缺席但 setup 不抛,快速记一条仍可用。

## 已知边界

- 正文**末尾**恰好以 `⚑pin` / `⌫arch` 结尾的字面文本会被当作状态哨兵。
- Amadeus 建索引时会先遮掉代码块;闪念盒不遮,闪念里围栏代码块的 `#include` 这种行首写法会算标签。
- 编辑闪念只改正文,时间戳保持原值(它是这条闪念的身份)。
- **月文件在 Amadeus 编辑器里保存过之后**,文件会多出 frontmatter 和 `<!-- a N -->` 块标记行 —— 这是宿主的块结构数据,插件完整保留:哨兵识别不受尾随标记影响,写回时哨兵永远落在内容行(绝不写出 `<!-- a 2 --> ⚑pin` 这种破坏宿主块结构的行),时间线上也不把标记行当正文展示。
- 在 Amadeus 里往月文件**末尾追加内容块**(拖文件/加段落),追加内容会被归入最后一条闪念的正文;若该条原本以 `⚑pin`/`⌫arch` 结尾,哨兵此时不再处于正文最末尾,状态会按「无哨兵」处理。手改月文件时,请保持哨兵在该条正文的最后一行。

## 和宿主的约定

`ctx.ui.mountChatBox` 用到的新字段:`submitOn: 'enter'`、`modelPicker: false`、`toolbar(el)`、`suggest: { trigger: '#', items(q) }`、句柄的 `insertText(text)`。`items(q)` 返回:

```js
[{ id: '产品/路线图', label: '#产品/路线图', value: '产品/路线图', insert: '#产品/路线图 ', hint: '19' }]
```

`insert` 是替换掉触发符和已输入部分的全文,`hint` 是右侧的小字。
